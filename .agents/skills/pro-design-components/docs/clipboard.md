## API

### ProClipboard

剪贴板复制组件，支持微前端子应用复制。

| 参数       | 说明           | 类型     | 默认值             |
| ---------- | -------------- | -------- | ------------------ |
| text       | 复制的文本内容 | `string` | -                  |
| copy-tip   | 复制提示       | `string` | `'点击复制'`       |
| copied-tip | 复制完成提示   | `string` | `'已复制到剪切板'` |

### Slots

| 插槽名  | 说明             |
| ------- | ---------------- |
| default | 点击复制触发 dom |
