# 更新日志

`pro-design-admin` 严格遵循 Semantic Versioning 2.0.0 语义化版本规范。

#### 发布周期

- 修订版本号：每周末会进行日常 bugfix 更新。（如果有紧急的 bugfix，则任何时候都可发布）
- 次版本号：每月发布一个带有新特性的向下兼容的版本。
- 主版本号：含有破坏性更新和新特性，不在发布周期内。

### 1.0.0

`2025-07-15`

- 🎉 正式发布 Pro Design Admin 1.0.0
- ✨ 基于 Vue 3、Vite、TypeScript 构建，企业级中后台管理框架
- ✨ 提供七种布局模式：侧边导航、侧边双列导航、顶部导航、顶部通栏侧边导航、侧边顶部导航共存、双列混合导航、全屏内容布局
- ✨ 内置权限管理方案，支持路由权限和按钮权限
- ✨ 集成国际化方案，支持多语言切换
- ✨ 支持暗黑模式和主题定制
- ✨ 集成 Pro Design Vue 全套组件库
- ✨ 支持微前端（Micro App）
- ✨ Mock 数据方案，快速开发原型
